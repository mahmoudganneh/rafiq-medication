# رفيق الدواء — Medication Companion

نموذج أولي محلي لتذكير الأدوية لكبار السن، مبني باستخدام HTML وCSS وJavaScript دون مكتبات خارجية.

## التشغيل
1. فك ضغط المشروع.
2. افتح `index.html` في متصفح حديث، ويفضل استخدام VS Code مع Live Server.
3. أضف الأدوية ومواعيدها بناءً على وصفة الطبيب أو تعليمات الصيدلي.
4. اضغط «تفعيل الصوت» مرة واحدة للسماح للمتصفح بتشغيل الصوت.
5. اترك الصفحة مفتوحة للحصول على التذكيرات.

## الوظائف
- إضافة وتعديل وحذف الأدوية ومواعيد التذكير.
- جدول يومي مع حالات «تم تأكيد التناول» و«لم يتم التأكيد».
- صوت تنبيه داخل الصفحة.
- سجل الجرعات وتصديره إلى CSV.
- تنزيل نسخة احتياطية بصيغة JSON.
- لوحة مبسطة لمقدم الرعاية.
- واجهة عربية RTL، وخط كبير، وتباين واضح، ودعم لوحة المفاتيح.

## حدود مهمة
- `LocalStorage` محلي للمتصفح والجهاز؛ لا توجد مزامنة بين الأجهزة ولا تشفير خاص للتخزين.
- التنبيهات تعمل فقط أثناء فتح الصفحة وتشغيل المتصفح. لا توجد إشعارات مضمونة بعد إغلاق الصفحة أو إطفاء الجهاز.
- الصوت قد يتطلب تفاعلاً أولياً من المستخدم، كما أن المتصفح أو نظام التشغيل قد يمنع الصوت.
- هذا النموذج ليس جهازاً طبياً ولا يوصي بالجرعات. يجب إدخال المعلومات وفق تعليمات الطبيب أو الصيدلي.
- حالة «لم يتم التأكيد» لا تثبت أن الجرعة لم تؤخذ.
- لا تستخدم بيانات صحية حقيقية حساسة في هذا النموذج التجريبي.
